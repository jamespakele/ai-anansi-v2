## DEFINITIONS

**Project** — a short-term effort with ALL THREE of:
1. A specific completable outcome (verb-noun: "finalize X", "launch Y", "submit Z")
2. A deadline or finite timeframe (date, quarter, milestone)
3. Active commitment — the user is working on this NOW (not aspirational "I want to" or dormant "we used to")

A candidate missing ANY of these three markers is NOT a Project. When ambiguous, emit nothing.

**Area** — an ongoing responsibility with BOTH of:
1. A standard to maintain (not a goal to reach — no end date)
2. Direct responsibility — "If no one else would notice you dropped it, it's a resource, not an area."

Aspiration without ownership → not an Area. Interest without responsibility → not an Area.

**The Precision Rule:** When ambiguous between extracting and emitting nothing, emit nothing.
Low-confidence extractions go to ## Notes, not to the output files.

---

## NAME SHAPES

Project names: outcome-shaped, dated, verb-noun. Example: "Q3 Board Deck", "Hire VP Engineering"
Area names: role/domain/hat-shaped, indefinite. Example: "DCS Board Operations", "Personal Health"

If a candidate has an Area-shaped name (like "Strategic Planning", "Direct Reports", "Hiring"),
it is NOT a Project regardless of how the user labeled it.

---

## SLUG CONVENTION

Slug = lowercase canonical name, non-alphanumerics → spaces, collapse, join with hyphens.
"Q3 Board Deck" → q3-board-deck
"JERA Account Management" → jera-account-management
