# Smart Brevity — The Cheat Sheet

> Ch. 23 of *Smart Brevity*. The condensed reference. **Skim this first**, then load the type-specific file.

---

## Guiding principles (4)

- **Authority** — be a trustworthy source. Distill, don't speculate.
- **Brevity** — respect the reader's time. Stay short, not shallow.
- **Humanity** — write like you speak. Real emotion, not Broadway.
- **Clarity** — frugal with words. Style for impact and scan.

---

## The process (in order)

### 1. Define your audience (60 seconds)

- Who is the smart reader?
- What do they need to know?
- Why is it significant?

### 2. Structure smartly

**Headline:**
- ≤6 words?
- Clear, specific, conversational?
- Muscular verbs? Active voice?

**First sentence:**
- One sentence?
- The thing they should remember?
- Distinct from the headline?

### 3. Explain significance with an axiom

- **Bold** "Why it matters" (or invent your own axiom)
- One sentence answering: why is this significant *to this audience*?

### 4. Invent your own axioms

Brainstorm versions of these for your industry / brand / voice:
- What's next
- The bottom line
- By the numbers
- The big picture
- Reality check
- Between the lines

### 5. Bullets for the rest

Use axioms as section headers; break the supporting data into bullets.

### 6. Review for accuracy, cohesion, humanity

- **Accurate** — didn't lose nuance? Bring it back if so.
- **Cohesive** — flows? Reintroduce transition phrases if cut too hard.
- **Human** — voice intact? If the rewrite reads robotic, breathe life back in.

## The rewrite checklist (universal)

- [ ] Tease ≤ 6 words. Active verb. Concrete.
- [ ] First sentence stands alone as the takeaway.
- [ ] **Why it matters** (or named axiom) bolded, 1–2 sentences, perspective-adding.
- [ ] One Big Thing identifiable in one sentence.
- [ ] Bullets used wherever 3+ related points exist.
- [ ] Bold marks key names / figures / dates.
- [ ] No adverbs, no foggy qualifiers, no throat-clearing.
- [ ] No SAT words, no journalese, no corporate jargon.
- [ ] Word count + reading time at top (if length warrants).
- [ ] Reads aloud without gasping.
- [ ] Friend can repeat the One Big Thing back after one read.

## Hard limits (memorize)

| Element | Limit |
|---|---|
| Tease / headline / subject | 6 words |
| First sentence | 1 sentence |
| Axiom + explanation | 1–2 sentences |
| Bullet | 1–2 sentences |
| Newsletter item | 200 words |
| Speech Big Thought | 15 words |
| TED Talk | 18 minutes |
| Slide text | 20 words |
| Total slides | 5–12 |
| Meeting agenda items | 3 max |
| Average attention | 26 seconds |

## The mantra

> Brevity is confidence. Length is fear.
